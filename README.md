\# STEP 3. 건설현장 구조물 결함 탐지 프로젝트



\## 1. 프로젝트 개요



본 프로젝트는 건설현장 구조물 이미지에서 발생하는 결함을 탐지하고 분할하는 것을 목적으로 한다.



YOLOv8s-Seg 모델을 사용하여 균열, 백태, 박리 및 박락을 탐지하고, 테스트 데이터 평가와 오탐 및 미탐 사례 분석을 통해 모델의 성능과 한계를 확인하였다.



\## 2. 탐지 대상



| 클래스 | 설명 |

|---|---|

| crack | 구조물 표면에 발생한 균열 |

| efflorescence | 구조물 표면에 발생한 백태 |

| spall\_detach | 콘크리트 표면의 박리 및 박락 |



\## 3. 개발 환경



| 항목 | 사용 환경 |

|---|---|

| 운영체제 | Windows |

| 프로그래밍 언어 | Python 3.13.14 |

| 딥러닝 프레임워크 | PyTorch 2.15.0+cpu |

| 객체 탐지 라이브러리 | Ultralytics 8.4.203 |

| 모델 | YOLOv8s-Seg |

| 학습 장치 | CPU |

| GPU 사용 | 사용하지 않음 |



\## 4. 데이터셋 구성



데이터셋은 학습, 검증, 테스트 세트로 구분하였다.



| 구분 | 이미지 수 |

|---|---:|

| Train | 4,036 |

| Validation | 40 |

| Test | 39 |

| 전체 | 4,115 |



클래스는 crack, efflorescence, spall\_detach 총 3개로 구성하였다.



데이터 분할 과정에서 동일한 원본 이미지가 학습 데이터와 테스트 데이터에 중복 포함되는 문제를 확인하였다. 중복 이미지를 별도 백업 폴더로 이동하고 원본 이미지 ID 기준으로 중복 여부를 재검사하였다. 최종적으로 데이터 분할 간 원본 ID 중복은 0건으로 확인하였다.



\## 5. 모델 학습



YOLOv8s-Seg 모델을 사용하여 세그멘테이션 학습을 진행하였다.



CPU 환경에서 전체 데이터 학습에 많은 시간이 소요되어, 파이프라인 동작 확인을 위한 소규모 테스트 학습을 수행하였다.



| 항목 | 설정 |

|---|---|

| 모델 | YOLOv8s-Seg |

| 학습 데이터 비율 | 0.5% |

| 학습 이미지 수 | 20장 |

| Epoch | 3 |

| Image Size | 640 |

| Batch Size | 2 |

| Device | CPU |



학습 결과 가중치는 `runs/segment/runs/step3\_small\_test/weights/best.pt`에 저장하였다.



※ 본 결과는 전체 데이터셋을 이용한 최종 학습 결과가 아니라 소규모 테스트 학습 결과이다.



\## 6. 테스트 데이터 평가



테스트 데이터 39장과 46개의 결함 인스턴스를 대상으로 세그멘테이션 성능을 평가하였다.



| 평가 항목 | 결과 |

|---|---:|

| Mask mAP50 | 0.000 |

| Mask mAP50-95 | 0.000 |



소규모 학습으로 인해 테스트 데이터에서 안정적인 결함 분할 성능을 확보하지 못하였다.



\## 7. Confidence Threshold 분석



검증 데이터에서 클래스별 Confidence Threshold를 탐색하였다.



| 클래스 | 선택 Threshold | 검증 F1 |

|---|---:|---:|

| crack | 0.001 | 0.3529 |

| efflorescence | 0.001 | 0.5965 |

| spall\_detach | 0.010 | 0.6286 |



검증 데이터에서 선택한 Threshold를 테스트 데이터에 동일하게 적용하여 성능을 확인하였다.



\## 8. 테스트 데이터 ON/OFF 평가 결과



| 클래스 | TP | FP | FN | TN | F1 |

|---|---:|---:|---:|---:|---:|

| crack | 0 | 0 | 13 | 26 | 0.0000 |

| efflorescence | 0 | 1 | 13 | 25 | 0.0000 |

| spall\_detach | 1 | 0 | 12 | 26 | 0.1429 |



전체 클래스의 Macro F1은 0.0476으로 확인되었다.



\## 9. 오류 사례 분석



테스트 데이터에서 발생한 오탐(False Positive)과 미탐(False Negative) 사례를 추출하여 분석하였다.



| 클래스 | FP | FN |

|---|---:|---:|

| crack | 0 | 13 |

| efflorescence | 1 | 13 |

| spall\_detach | 0 | 12 |



오류 사례를 확인한 결과, 표면의 색상과 질감이 유사한 결함 간 혼동이 발생할 수 있음을 확인하였다.



주요 개선 방향은 다음과 같다.



\- 균열의 굵기와 대비가 다양한 학습 이미지 보강

\- 백태와 박리·박락의 구분이 명확한 데이터 추가

\- 결함 경계가 모호한 이미지의 라벨링 기준 재검토

\- 오탐 및 미탐 사례를 활용한 데이터와 라벨링 기준 개선

\## 11. 결론



본 프로젝트에서는 YOLOv8s-Seg 모델을 이용하여 건설현장 구조물의 균열, 백태, 박리 및 박락을 탐지하는 실습을 진행하였다.



데이터셋의 중복 여부를 확인하고 정리하였으며, 소규모 학습과 테스트 데이터 평가, 클래스별 Threshold 탐색 및 오류 사례 분석을 수행하였다.



테스트 결과 모델의 탐지 성능은 낮게 나타났으며, 특히 미탐 사례가 다수 확인되었다. 이를 통해 충분한 학습 데이터 확보와 클래스별 특징을 반영한 라벨링 기준 개선이 필요함을 확인하였다.



향후 학습 데이터 보강과 학습 조건 개선을 통해 모델의 성능을 향상시키고자 한다.
